# Copilot starter brief — A1 Unit 1 only

Copy-paste this into Copilot Chat in VS Code, in **Agent** mode, with permissions on **Assisted**.

> Build only A1 Unit 1 of my approved Italian-only CEFR plan: visual, verbal, and written practice from pictures/scenes, no English translation as the main route, plus Add a Word and Add a Topic from the front end. It must be an offline-first web app I can add to the Home Screen on iPhone and iPad.
>
> Work in small steps and stop after each step so I can check it. After every step, explain in plain English what each file does and what happens if I remove it. Keep files small, add comments, and give me one way to test that step. Do not build A2, B1, or the rest of A1 yet.

## Work in this order — one step, then stop and check

1. Set up only: initialise git, make the first commit, and create the empty offline web-app scaffold. Stop. Check: it opens in a browser.
2. Data first: the word / topic data shape for A1 Unit 1 only. Stop. Check: you can explain the shape back in plain English.
3. One visual exercise: hear a phrase, tap the matching picture. Stop. Check: it works with the Unit 1 words.
4. One verbal and one written exercise: speak from a picture cue, and build a sentence from word tiles. Stop. Check: both work offline after the first online load.
5. Add a Word and Add a Topic: add them from the front end and see them appear in practice. Stop. Check: a word you add shows up in the review queue.
6. Stop for good after Unit 1. Check the actual Copilot credit use, then decide together whether to expand.

If any step produces code you cannot explain back, do not move on. Ask Copilot to rewrite it more simply first.

## When code works but you don't understand it

- "Explain this file to me like I'm new — what does it do, and what happens if I remove it?"
- "Why did you choose this approach, and what's a simpler alternative?"
- "Add comments and break this into smaller pieces I can follow."
