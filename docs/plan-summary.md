# Approved plan — short version

Full plan: `Italian-only-CEFR-plan.md` (in Muse, approved 2026-11-11).

- Italian only for now. Sicilian deferred as a future layer.
- Learn by associating images / objects / scenarios directly with Italian phrases. English only as a hidden hint.
- CEFR A1–C2, starting at A1 as a child. Each level is 8–12 thematic units, each unit a scenario.
- Visual, verbal, and written practice in every unit. Spaced repetition. Seen / heard / said / written tracking.
- Free-response conversation: guided roleplay, talk about a picture, story continuation. Gentle recast feedback.
- Add a Word / Add a Topic from the front end.
- Offline-first web app, Add to Home Screen. Live conversation needs a connection; offline uses scripted branching.
- Build order: Phase 1 A1, Phase 2 A2 + roleplays, Phase 3 B1 then B2. Start with A1 Unit 1 only.
